# ReelStudio — Instagram Reel editing assistant

A small, browser-based prototype for trying visual treatments on a Reel before sharing it. It is branded for the creator workspace `@messy_noxmere`; it does not connect to or publish to Instagram.

## Run it

Open `index.html` in a recent desktop version of Chrome or Microsoft Edge. Select a local video, choose one of the three edit ideas, change the on-screen text, set trim start/end times, and choose **Export my Reel**. The result downloads as a WebM video. Keep the tab open during export.

## What works

- Local video preview in a 9:16 crop
- Three visual presets, editable title and supporting line
- Start/end trim controls
- Browser-side export of the preview with audio where supported
- Drag-and-drop video selection; no upload or account login

## Current limitations

- The “AI edit ideas” are starter presets, not generated by a connected AI model.
- Export is WebM and requires MediaRecorder support (Chrome/Edge recommended). Instagram publishing is not implemented.
- This is a prototype: review the exported video and check your browser's support before relying on it for final production.

## Privacy and safety

Videos are loaded as local browser object URLs and are not sent to a server. Never enter your Instagram password into this prototype. It is not affiliated with Instagram.
